# Datos

Coloca aquí `mapa.osm`: extracto de OpenStreetMap recortado al polígono del campus.

Se puede exportar desde https://www.openstreetmap.org/export (botón *Export* → seleccionar el área).
Los IDs de semáforos y tramos en `src/sigma_sim.py` corresponden a esa red; si cambias el recorte, actualízalos.
